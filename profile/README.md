# 🪲 Beetle

**Beetle is an open suite of bilingual, monolingual and polyglot *small* language models for studying how models learn — and in particular how they pick up a second language.** Every model is checkpointed densely through training, so you can inspect *how* learning happens, not just whether it did. From a download-free CPU quickstart to billion-token research runs, the whole pipeline — data, training, analysis, and a no-code explorer — is open source.

Introduced in *Beetle: A Bilingual Model Suite for Modelling Second-Language Processing* (EMNLP 2026).

## Repositories

| Repo | What it is | Tutorial |
|---|---|---|
| **[beetlelm](https://github.com/beetlelm/beetlelm)** | Core training framework — train a real bilingual model on CPU in ~15s, then scale to multi-GPU runs. | [Guide](https://beetlelm.github.io/docs.html#beetlelm) |
| **[beetle-data](https://github.com/beetlelm/beetle-data)** | Bilingual data-preparation pipeline — stream, decontaminate, tokenize and pretokenize corpora. | [Guide](https://beetlelm.github.io/docs.html#beetle-data) |
| **[beetle-analyze](https://github.com/beetlelm/beetle-analyze)** | Evaluation and interpretability toolkit — BLiMP scoring, learning curves, cross-lingual analysis. | [Guide](https://beetlelm.github.io/docs.html#beetle-analyze) |
| **[beetle-explorer](https://github.com/beetlelm/beetle-explorer)** | No-code Colab explorer — load any model at any training step and generate text in your browser. | [Guide](https://beetlelm.github.io/docs.html#beetle-explorer) |
